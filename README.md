# 메이크노브 비즈센터 MVP

든든한 해외영업 파트너, 메이크노브. 한국 기업용 베트남 해외영업 서비스의 소개 사이트와 고객용 비즈센터 시안입니다.

- `biz/` 소개 사이트: 랜딩, 서비스 소개 5개, 플랜, 사용가이드, 칼럼
- `adcenter/` 비즈센터 시안: 로그인, 대시보드, 파트너 후보, 파트너 상세, 미팅 캘린더, 토큰·플랜, 이용안내
- `admin/` 관리자 시안: 대시보드, 고객사, 파트너, 후보 배정, 미팅 관리, 회의록, 토큰 장부, 사이트 관리

관리자에서 바꾼 내용은 같은 브라우저의 비즈센터와 소개 사이트에 바로 반영됩니다. 시연용이라 데이터는 브라우저에만 저장됩니다.

화면에 나오는 파트너와 수치는 모두 샘플 데이터입니다. 정적 HTML이라 별도 서버 없이 열립니다.
